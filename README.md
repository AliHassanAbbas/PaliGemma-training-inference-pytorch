# PaliGemma: Training and Inference Study with PyTorch

A notebook-based study of the PaliGemma vision-language model workflow, with a focus on understanding multimodal model components and the training/inference path represented in the notebook.

## What to inspect
- How image and text inputs are represented
- The vision and language components and how their representations interact
- The training or adaptation procedure included in the notebook
- The inference and output-generation flow

## Run
Open the notebook in Jupyter or Google Colab. Review its first setup cells for the required packages, model assets, data sources and hardware expectations before running it. Follow the notebook's stated access and licensing requirements for any external model assets.

## Scope
This repository is a practical learning implementation/study, not a claim that the original PaliGemma model was pretrained from scratch. Check the notebook for the exact training scope, weights, dataset and compute requirements.
